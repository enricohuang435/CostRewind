# CostRewind
A Web-Based Version Management and Comparison System for Construction Cost Data

**Course:** COMP3000 - Computing Project

**Supervisor:** Nancy Girdhar

## Project Vision
Construction cost estimators often need to compare several versions of an estimate as designs change. Checking spreadsheet versions manually takes time and makes it easy to miss changes to individual cost items.
CostRewind aims to give estimators a single version history for each project and let them compare any two saved versions. It will preserve each imported version and use a stable item key to match cost items across versions. A row-by-row comparison will show which items were added, removed or modified, along with changes in quantities, rates and amounts.
